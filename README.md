# MyDockFinder

macOS Dock 增强工具（Windows），对标 MyDockFinder 原版应用，提供快速启动、窗口管理、消息提示、天气、任务进度等增强能力。

## 功能特性

### Dock 栏与图标管理
- **图标类型**：程序快捷方式（.lnk）、可执行文件（.exe）、文件、文件夹、UWP 应用、系统图标（下载/文档/图片/音乐/视频/此电脑/**天气预报**）
- **添加方式**：右键 Dock 空白区 →「添加系统图标」；文件/文件夹拖入 Dock（支持批量）
- **交互**：左键启动/激活（文件夹展开内容）、悬停放大（可调强度）、拖拽排序持久化、拖出删除或右键移除
- **右键菜单**：打开 / 打开文件位置 / 属性（系统属性对话框）/ 重命名（快捷方式）/ 从 Dock 移除 / 固定到 Dock；文件夹额外提供「文件夹设置」（缩略图开关 + 排序方式）

### 窗口与任务管理
- **窗口预览**：悬停运行中图标显示实时窗口缩略图（进程精确匹配，支持 UWP），大小/延迟/开关可配置
- **任务进度**：文件复制、浏览器下载、播放器进度显示在 Dock 图标上（标题解析 + 进度条控件双通道，与系统任务栏进度同步）
- **最小化到 Dock**：窗口最小化时播放三种可选动画（飞入 / Genie 吸入 / 缩放吸入），时长与缓动可配置

### 系统与增强信息
- **消息计数**：QQ / 微信 / 企业微信 / 钉钉 / 飞书 / 阿里旺旺 / Outlook 等 17 个应用未读角标，新消息弹跳提示；**仅统计未读数量，不读取聊天内容**（官方算法为原创，无公开接口）
- **天气**：添加「天气预报」系统图标到 Dock，显示实时天气（图标+温度）；悬停显示未来 3 天预报。**图标为实时天气、预览窗口为未来天气，两者可能有出入**（官方设计如此）；城市/单位/更新频率可配置
- **文件夹展开**：左键打开文件夹面板，支持二级目录递归、名称/时间/大小排序、文件拖出到桌面（按系统默认移动/复制）、悬停显示完整文件名

### 视觉与效果
- **亚克力模糊背景**：Win32 直接合成（非 CSS 模拟），强度可调，tint 颜色自定义，GDI 圆角裁切；系统不支持时自动降级 CSS 半透明
- **三种最小化动画**：D3D11 加速合成（Electron 底层 GPU 渲染）
- **深/浅主题**：跟随系统或手动切换，全面适配
- **多显示器**：Dock 跟随鼠标所在显示器

## 技术栈与架构

Electron 43 · React 19 · TypeScript · Vite 8 · Zustand · framer-motion · koffi（Win32 直调）

主进程模块化：`main.ts`（入口/窗口/IPC）、`acrylic.ts`（亚克力）、`preview.ts`（窗口预览）、`progress.ts`（任务进度）、`icons.ts`（图标缓存）、`uwp.ts`（商店应用）、`admin.ts`（管理员检测）、`ps.ts`（PowerShell 异步）、`log.ts`（日志）

- 全部主进程阻塞调用异步化（无 `execSync`），运行状态主进程统一推送（5s tick + diff），渲染层零轮询
- koffi 类型幂等注册（多模块共享全局注册表），空闲 CPU 实测 0%

## 开发

```bash
pnpm install
pnpm dev        # 开发模式（vite HMR + electron）
pnpm build      # 类型检查 + 渲染构建 + 主进程编译
pnpm lint       # oxlint
```

## 打包

```bash
pnpm dist       # NSIS 安装包 + Portable 便携版（release/）
pnpm dist:dir   # 仅解包目录（快速验证）
```

## 设置说明

设置面板分区：外观（主题/强调色/Dock 底色/位置/图标大小间距/圆角/放大/模糊）、预览（开关/延迟/大小）、最小化（动画类型/时长/缓动）、天气（城市/单位/频率）、消息提示（显示开关/各应用开关）、行为（自动隐藏/天气）、系统（开机自启）

## 数据与日志

- 设置与固定应用：`%APPDATA%\mydockfinder\settings.json`（含文件夹显示设置 meta）
- 运行日志：`%APPDATA%\mydockfinder\logs\main.log`（2MB 自动轮转）

## 已知限制（对齐官方）

- **管理员模式**：检测到管理员运行时 Dock 顶部显示提示条，拖放动画降级（官方明确不建议管理员账号运行）。日志会标记运行模式
- **UWP 图标缺失**：部分系统组件（如 Game Bar）无 44px logo，显示占位图标
- **Win10 兼容**：亚克力效果在 Win10 1809+ 可用，Win7 及更早不支持
